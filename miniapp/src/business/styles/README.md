# Стили интерфейса

Единственная точка подключения — `index.css`. Исключение — `ui-kit.css`: базовые стили элементов управления подключаются в `main.tsx` раньше темы, чтобы тема Опоры их переопределяла. Порядок импортов сохраняет приоритеты существующего интерфейса; стили компонентов не подключаются повторно из TSX.

| Файл | Ответственность |
| --- | --- |
| `tokens.css` | Основная палитра двух тем, шрифт, фокус, безопасные области экрана |
| `base.css`, `shell.css`, `responsive.css` | Базовая разметка, оболочка и адаптация |
| `ui-controls.css`, `controls.css` | Тема элементов управления (`UiControls.tsx`) и формы |
| `widgets.css`, `surfaces.css`, `dark-surfaces.css` | Общие блоки и поверхности |
| `home.css`, `business.css`, `settings.css` | Главная, бизнес, настройки |
| `catalogue.css` | Каталог и форма задачи |
| `documents.css`, `workspace.css` | Документы и этапы подготовки |
| `chat.css`, `ai-results.css` | Чат и результаты AI |
| `feedback.css` | Состояния загрузки, источников и действий |
| `light-theme.css` | Светлые поверхности и тематические исключения компонентов |

Семантические цвета `--ink`, `--muted`, `--surface`, `--canvas`, `--line`, `--accent`, `--brand` объявляются только в `tokens.css`. Не добавляйте новую палитру в файл экрана. Геометрия принадлежит компоненту; тематические исключения — файлу темы. Стеклянные градиенты и оттенки отдельных изображений не являются цветами текста и сохраняются отдельно.

При изменениях находите существующий селектор и правьте его владельца, вместо добавления очередного файла исправлений. Общие поверхности могут переопределять базовое оформление; этот приоритет намеренный. Не переставляйте импорты ради алфавитной сортировки.

Удалены селекторы отсутствующих статических блоков. Динамические классы `page-*`, `nav-*`, `funding-status-*`, `status-*`, `theme-preview-*` и классы `ui-*` из `UiControls.tsx` сохранены. Пустые правила не нужны. Изменения проверяются в двух темах и Chromium/WebKit, включая 320 px.
